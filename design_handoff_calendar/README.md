# Handoff: Редизайн раздела «Календарь» (Моё пространство)

## Overview
Полный редизайн экрана **«Календарь»** учительского раздела «Моё пространство». Сейчас календарь
построен на `react-big-calendar` и показывает два типа событий — **уроки** и **дедлайны выдач**.
В систему добавился новый функционал **«Дела» (todos)**, и задача — собрать единый, плотный и
красивый календарь, где на одной сетке живут **три** типа событий (уроки · дедлайны · дела),
плюс правый рабочий рейл (сводка + фильтры + дела на сегодня) и боковой инспектор события.

Цель — повысить плотность и читаемость сетки, дать быстрое создание любого события прямо из
ячейки и свести «что требует внимания сегодня» в один экран, не уходя на отдельную страницу «Дела».

## About the Design Files
Файлы в этом бандле — **дизайн-референс, сделанный в HTML** (`Календарь - Моё пространство.dc.html`).
Это прототип, показывающий **итоговый внешний вид и поведение**, а НЕ продакшен-код для копирования.
Прототип написан на внутреннем формате Design Component (шаблон + JS-класс логики) и использует
выдуманные демо-данные за июнь 2026.

Задача — **воссоздать этот дизайн в существующем кодовом окружении проекта**: React 18 +
Ant Design 5 + `react-big-calendar` + PocketBase (`api`-слой). Не нужно тащить разметку из HTML
дословно — нужно переложить визуал и поведение на компоненты вашего стека, опираясь на уже
существующие паттерны раздела (см. `TeacherCalendar.jsx`, `TodosPage.jsx`, `ui/`, `lessonTime.js`,
`groupColor.js`). Цвет, типографика, расписание пар и палитра групп — берутся из существующих
токенов, ничего нового вводить не нужно.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, состояния и микроинтеракции.
Воспроизводить близко к пиксельной точности средствами вашего UI-кита (AntD + tokens.css).
Шрифт раздела — **Geist** (UI) + **Geist Mono** (время/числа), как и в остальных экранах «Моё пространство».

## Что нового по сравнению с текущим календарём (ОБЯЗАТЕЛЬНО реализовать)

Текущий `TeacherCalendar.jsx` рисует только уроки и дедлайны на дефолтных видах react-big-calendar,
а просмотр/редактирование идёт через одну AntD-модалку. Прототип добавляет следующее.

### 1. Третий тип событий на сетке — «Дела» (todos)
Дела из `api.getTodos()` теперь рендерятся прямо в календаре наравне с уроками и дедлайнами.
- Размещаются по `due_date` (дело без срока на сетку не попадает — оно во «Входящих» страницы «Дела»).
- Визуально — **белый чип с рамкой `#E8EAEE`** и **интерактивным чекбоксом** слева; цвет чекбокса =
  цвет привязанной группы (если у дела есть `group`/привязка), иначе teal `#0D9488`.
- **Чекбокс кликается прямо на сетке** (`e.stopPropagation()` чтобы не открыть инспектор) →
  вызывает `api.updateTodo(id, {done})` (а с учётом повтора — `api.completeTodo`, см. TodosPage).
- Выполненное дело: текст зачёркнут, цвет `#B5BAC4`.
- Дело с `priority:'high'` (и не выполненное) — красный флажок-иконка справа `#E11D48`.
- В виде «Месяц» дела стоят в общем порядке ячейки **после** дедлайнов и уроков
  (порядок сортировки: `deadline → lesson → todo`).
- В виде «Неделя» дела (как и дедлайны) попадают в полосу **«весь день»** над тайм-сеткой.

### 2. Кастомный вид «Неделя» — тайм-сетка по парам школы
Вместо часовой шкалы react-big-calendar — **сетка строк по парам** из `lessonTime.js` (`PAIRS`):
строки `Нулевая · 09:00`, `1-я пара · 10:15`, … `5-я пара · 17:45`. Колонки — 7 дней недели.
- Левая колонка (66px) — время старта пары (Geist Mono) + подпись пары.
- Сверху — строка-заголовок дней (ДОВ + число, сегодня — синий кружок `#2B4BFF`) и
  полоса **«весь день»** для дедлайнов/дел.
- Урок раскладывается в ячейку своей пары (по `time_slot`, fallback — `guessSlot` по `date_plan`).
- Клик по **пустой ячейке** пары → быстрое создание урока на этот день/пару (см. п.5).
- Карточка урока в неделе крупнее: тема + строка `время · группа` (Geist Mono).

### 3. Правый рабочий рейл (330px) — НОВОЕ
Постоянная панель справа (скрывается тви́ком `showRail`). Три блока:

**a) Сводка периода** — 4 карточки-метрики за текущую неделю:
- `Уроков` (синяя), `Дедлайнов` (янтарная), `Дел открыто` (teal), `Требует внимания` (rose).
- «Требует внимания» — **производное число**: `просроченные невыполненные дела + дедлайны на сегодня`.
  Значение красное `#E11D48`. Это сигнальная метрика, ради неё блок и существует.

**b) Фильтры «Показывать на сетке»** — три тумблера-строки: Уроки `#2B4BFF` / Дедлайны `#D97706` /
Дела `#0D9488`. У каждого — квадрат-свотч, счётчик всего и toggle-переключатель. Выключение типа
убирает его события со всех видов (аналог текущих `showDeadlines` + `groupFilter`, но обобщённо).
Ниже — **легенда групп**: пилюли с цветной точкой (цвет = `groupHex(group)`), клик фильтрует по группе.

**c) «Дела на сегодня»** — список дел с `due_date ≤ сегодня` (просроченные + сегодняшние),
сортировка по дате. Каждая строка: чекбокс (toggle), заголовок, чип срока
(`сегодня` синий / `−N дн` красный для просроченных / `D июня`), чип группы, флажок приоритета.
Внизу пунктирная кнопка **«Новое дело»** → открывает create-модалку на вкладке «Дело».

### 4. Боковой инспектор события (slide-over) — НОВОЕ
Клик по **любому** событию открывает выезжающую справа панель 380px (анимация `translateX`,
0.2s, `cubic-bezier(.2,.8,.2,1)`) поверх затемнения. Заменяет «просмотр» в текущей модалке
(редактирование по кнопке-карандаш по-прежнему ведёт в полноценную форму урока/дела).
Содержимое адаптируется под тип:
- **Чип типа** в шапке (Урок/Дедлайн/Дело) в цвете типа.
- Заголовок; у дела — крупный чекбокс слева, зачёркивание при выполнении.
- Чипы: группа (цвет группы) + статус (для урока: запланирован/идёт сейчас/проведён/отменён;
  для дедлайна: «дедлайн выдачи»).
- Мета-строки: время/дата/посещаемость (урок) · срок/назначено N ученикам (дедлайн) · срок/приоритет (дело).
- **Материалы** (урок): список прикреплённых работ/файлов; если `mats===0` — янтарный предупреждающий блок
  «Материалы ещё не прикреплены» с кнопкой «Собрать».
- **Связи**: для дедлайна — кнопка перехода к работе; для дела — привязанный урок/ученик/работа.
- Низ: основная кнопка действия (контекстная: «Отметить посещаемость» / «Открыть работу» /
  «Отметить выполненным»), кнопка-карандаш (редактировать), кнопка-корзина (удалить, rose).

### 5. Единое быстрое создание из сетки — НОВОЕ
- Кнопка **«Создать»** в шапке и **`+`** в ячейке месяца / клик по пустой ячейке недели → модалка.
- Модалка с **табами Урок / Дедлайн / Дело** (Segmented). Поля адаптируются:
  - Урок: тема, группа, дата+время, **чипы выбора пары** по расписанию (`PAIRS`).
  - Дедлайн: название работы, группа, срок.
  - Дело: «что нужно сделать», группа, срок (без пар).
- Дата предзаполняется днём, из ячейки которого открыли создание.
- Сохранение → соответствующий `api.createLesson / создать дедлайн (session.deadline) / api.createTodo`.

### 6. Прочие детали, отсутствующие сейчас
- Статус **«идёт сейчас»** у урока: рамка-обводка `#2B4BFF` + пульсирующая цветная полоса (`@keyframes`).
- Плотность сетки — тви́к `density` (`comfortable` = 3 события и min-height 118px на ячейку /
  `compact` = 2 события и 96px).
- Индикатор материалов: 📎-иконка-скрепка в углу события (сейчас это эмодзи в title — заменить на иконку).
- Выходные (сб/вс) — приглушённый фон ячеек и серые числа; «не июнь» (дни добора сетки) — ещё бледнее.

## Interactions & Behavior
- **Переключение видов** — Месяц/Неделя/День/Список; сохранять выбранную дату при переключении.
- **Навигация периодов** — «Сегодня / ‹ / ›» сдвигает на месяц или неделю по активному виду.
- **Клик по событию** → открыть инспектор (slide-over). Клик по фону/✕ — закрыть (fade 0.15s).
- **Клик по чекбоксу дела** (на сетке, в рейле, в инспекторе) — `stopPropagation`, оптимистичный
  toggle `done`, затем `api.updateTodo`/`api.completeTodo` (повторяющиеся дела создают следующий экземпляр).
- **Клик `+`/пустой ячейке** → create-модалка с предзаполненной датой/парой.
- **Тумблеры фильтров** — мгновенно скрывают/показывают тип на всех видах.
- **Drag-перенос событий** (как в текущем `TeacherCalendar` через `withDragAndDrop`): перетаскивание
  урока/дедлайна меняет дату → `persistLessonDate`/`persistDeadline` оптимистично + `api.update…`.
  *(В HTML-прототипе drag не вживлён — сохранить существующую механику из кода.)*
- **Анимации:** slide-over `translateX(24→0)` + fade 0.2s `cubic-bezier(.2,.8,.2,1)`; затемнение
  fade 0.15s; «идёт сейчас» — `wsPulse` 2s бесконечно; hover на `+` — opacity 0→1 0.12s.
- **Состояния:** loading (как сейчас — `message.error` при сбое загрузки); пустой период;
  «материалов нет» — янтарный блок в инспекторе.

## State Management
Расширить состояние текущего `TeacherCalendar`:
- Существующее: `groups, works, lessons, deadlines, groupFilter, showDeadlines, view, date, modalOpen, editing, saving`.
- Добавить: `todos` (из `api.getTodos()`), `filters {lesson, deadline, todo}` (обобщить `showDeadlines`),

- Загрузка: добавить `api.getTodos()` в `Promise.all` функции `load()`.

  и `groupFilter`); todo попадает на сетку только при наличии `due_date`.

## Data Contracts (существующие модели PocketBase)

**Урок (`lessons`)** — `api.getLessons()`:
`{ id, title, group (id), date_plan (ISO), status: 'planned'|'done'|'cancelled', time_slot, materials: [{type:'work'|'material', id, title, url?}], expand.group.name }`.
Время: `lessonStartEnd(l)` / `endForLesson` из `lessonTime.js`; `time_slot` коды: `"0"|"N"|"Na"/"Nb"|"N-M"(интенсив)`.

**Дедлайн** — `api.getSessionsWithDeadline()`: запись сессии с полем `deadline (ISO)`; заголовок —
`expand.work.title || student_title || expand.mc_test.title || …`. all-day событие.

**Дело (`todos`)** — `api.getTodos()`:
`{ id, title, due_date (ISO|''), done (bool), priority: 'high'|'normal', repeat: ''|'daily'|'weekly'|'monthly', folder (id|''), expand.folder, links/привязки: ученик/урок/работа }`.
Мутации: `createTodo, updateTodo, completeTodo(t)→{updated,next}, deleteTodo`. Папки: `getTodoFolders`.
