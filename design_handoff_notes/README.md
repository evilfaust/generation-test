# Handoff: Редизайн страницы «Заметки» (Моё пространство)

## Overview
Редизайн страницы **«Заметки»** (маршрут `/app/notes`, компонент
`NotesWorkspace.jsx`) приложения Lemma / ege-tasks.

Сейчас страница — две панели: список заметок слева и редактор (BlockNote)
справа. Редактор занимает почти весь экран, но контекст заметки (урок, ученики,
вложения, связи) либо спрятан, либо вставлен в поток над текстом, а правое
пространство простаивает.

Цель редизайна — сделать «Заметки» **плотнее и функциональнее**, не меняя
дизайн-язык: типизация заметок, быстрый захват мыслей, и главное — **третья,
контекстная панель справа**, которая превращает заметку из «листа с текстом» в
рабочий узел: связь с уроком и учениками, задачи из чек-листа, вложения,
бэклинки. Это укладывается в общий вектор продукта — «одно окно» для учителя.

## About the Design Files
`Заметки - Моё пространство.dc.html` — **design reference** (HTML-прототип):
показывает итоговый вид, состав панелей и состояния. Это **НЕ** production-код.

Реализовать дизайн нужно **внутри существующего кода** (`generation-test/ege-tasks`,
React + Ant Design + Vite), переиспользуя принятые паттерны: токены
`src/theme/tokens.css`, компоненты `src/components/workspace/ui/` (`Chip`,
`WorkspacePageHeader`, `EmptyState`), BlockNote-редактор и `NoteAttachments`.
Инлайн-стили из прототипа в код не переносить — всё на CSS-переменные/классы
(`NotesWorkspace.css`) и AntD-компоненты.

> Открой `.dc.html` в браузере, чтобы увидеть дизайн живьём. `support.js` —
> рантайм прототипа, в кодовую базу не нужен.
>
> **Важно про ширину:** макет рассчитан на ширину рабочей области ≥ ~1200px
> (три панели с min-width). В узком окне включается горизонтальный скролл, а на
> планшете/телефоне панели схлопываются вертикально (см. «Адаптив»).

## Fidelity
**High-fidelity.** Цвета, типографика, отступы и состояния финальные, все значения
совпадают с `tokens.css` — использовать переменные, не хардкодить хексы.

## Архитектура страницы

Страница рендерится внутри существующего AppShell (сайдбар + топбар уже есть —
**заново не делать**; в прототипе они для контекста).

`WorkspacePageHeader` остаётся (иконка `FileTextOutlined`, accent `amber`,
заголовок «Заметки», подзаголовок). **Изменение в шапке:** кнопка «Новая заметка»
становится **split-button** — основное действие создаёт обычную заметку, стрелка
открывает меню выбора типа (см. «Типы заметок»).

Ниже — рабочая область на всю высоту, **три панели** (flex, `gap:14px`):

1. **Список** — фикс. ширина `312px`.
2. **Редактор** — растягивается (`flex:1`, `min-width:440px`).
3. **Контекст** (НОВОЕ) — фикс. ширина `296px`, сворачивается.

Каждая панель — белая карточка (`--bg-raised`, `border --rule`, `radius 12px`,
`--shadow-sm`) со своим внутренним скроллом; внешнего скролла страницы нет.

## НОВЫЕ ФИЧИ — функционал

### 1. Типы заметок (НОВОЕ)
Заметка получает поле **type** (одно из):

| Тип | Значение `type` | Тон | Иконка | Назначение |
|---|---|---|---|---|
| Заметка урока | `lesson` | violet | FileText | привязана к уроку, ученики группы |
| План | `plan` | blue | (КТП/list) | подготовка, контрольная, вариант |
| Идея | `idea` | amber | Bulb | быстрая мысль, методическая находка |
| Звонок | `call` | rose | Team | звонок/сообщение родителю |
| Наблюдение | `obs` | teal | CheckSquare | наблюдение по ученику |

**Функционал типа:**
- Определяет иконку и цвет в списке и в шапке редактора (пилюля типа, кликабельна
  → смена типа).
- Влияет на **шаблон** при создании (split-button в шапке): «заметка урока»
  предзаполняет блок «Ученики» и просит выбрать урок/группу; «план» —
  чек-лист-болванку; «звонок» — поля «кому/итог» и т.п.
- Тип — это фильтр в списке (чипы) и потенциальная семантика для других разделов
  (напр. «звонок» с незакрытым итогом может всплывать в «Сегодня»).

> Реализация в данных: добавить `teacher_notes.type` (enum-строка, default
> `lesson` если есть `lesson`, иначе `idea`/`plan`). Существующий флаг
> `is_inbox` сохраняется и ортогонален типу.

### 2. Быстрый захват мысли (НОВОЕ)
Над поиском в списке — поле **«Быстро записать мысль…»** (тёплый amber-фон).
**Функционал:** ввод + Enter мгновенно создаёт заметку типа `idea` с
`is_inbox: true` и НЕ открывает редактор (фокус остаётся в поле — можно строчить
мысли подряд). Только что созданная подсвечивается в списке. Цель — нулевое
трение для захвата на ходу (в т.ч. с телефона).

### 3. Фильтры по типам (НОВОЕ)
Под сегментами Все/Инбокс/Архив — горизонтальный ряд чипов:
`Все · Уроки · Планы · Идеи · Звонки · Наблюдения`. Активный — синяя заливка
(`--accent-soft`/`--accent-ink`), остальные — белые с цветной точкой тона типа.
Фильтрует видимый список по `type` (комбинируется с поиском, классом, сегментом).

### 4. Контекстная панель «Контекст» (НОВОЕ, ключевое)
Правая панель `296px`, сворачивается стрелкой в шапке (состояние в
localStorage/профиле). Секции сверху вниз:

**4.1 Урок** — если заметка привязана к уроку (`note.lesson`): карточка с
предметом/группой, датой и временем, ссылкой на КТП, кнопкой **«Открыть урок →»**
(navigate в календарь/урок). Двусторонняя связь урок↔заметка уже есть в коде
(`api.getOrCreateLessonNote`, `getLessonNote`) — здесь она вынесена в наглядный
блок. Если урока нет — кнопка «Привязать к уроку».

**4.2 Ученики группы** — чипы отмеченных учеников (аватар-инициалы + имя в тоне) +
кнопка «+ отметить». **Функционал (расширяет существующий «Ученики группы»):**
отметка ученика (а) вставляет в тело заметки персональный раздел-заголовок (уже
есть — `tagStudents` + `onTagStudents`), и (б) добавляет ссылку
`links: {type:'student', id, name}` (уже есть), благодаря чему заметка
показывается в карточке ученика. Панель просто визуализирует текущие
`links[type='student']` и даёт быстрый доступ. Требует `note.group`.

**4.3 Задачи из заметки (НОВОЕ)** — чек-лист-строки тела заметки агрегируются в
трекаемые задачи: прогресс «N / M», список с чекбоксами, кнопка
**«В Все задачи»**. **Функционал:** любой чекбокс-блок в теле (BlockNote
`checkListItem`) парсится в задачу; отметка done синхронизируется обратно в тело;
кнопка экспортирует незакрытые пункты в глобальный раздel «Все задачи» с
обратной ссылкой на заметку как источник. Это связывает заметки с задачами
учителя (заметка → план действий). 
> Реализация: читать блоки тела типа `checkListItem` (`extractNoteText` уже
> ходит по дереву — добавить сбор чек-айтемов с их `checked`). Для экспорта —
> создать записи в коллекции задач со ссылкой `source: note.id`.

**4.4 Вложения** — компактный список файлов заметки (вынесен из потока редактора,
где раньше стоял `NoteAttachments` над текстом). Файлы из урока помечены чипом
«из урока» (read-only, как сейчас `lessonFiles`). Снизу — компактная drop-зона
(«Перетащите файлы — попадут в Библиотеку») и «Из Библиотеки». Это тот же
`NoteAttachments`, переразмещённый в панель и ужатый по вертикали.

**4.5 Связанные / бэклинки (НОВОЕ)** — список заметок и уроков, ссылающихся на
текущую (или на которые ссылается она). **Функционал:** wiki-стиль связей между
заметками — в теле можно упомянуть другую заметку (`[[...]]` или slash-команда
«ссылка на заметку»), и она появляется здесь с обеих сторон. Даёт «вторую память»
по темам/ученикам. 
> Реализация: хранить связи в `teacher_notes.links` новым `type:'note'`
> (`{type:'note', id}`); бэклинки — обратный поиск заметок, где `links` содержит
> текущий id. На первом этапе можно показывать только исходящие ссылки.

**4.6 История** — «Изменено …», «Создано …» (из `updated`/`created`).

### 5. Панель форматирования редактора (НОВОЕ)
Тонкий тулбар между мета-строкой и телом: заголовок, **B**, список, чек-лист,
**формула (Σ)**, изображение, таблица, «Ученики группы»; справа — счётчик
«N слов · ~M мин · «/» команды». **Функционал:** кнопки = быстрые вставки блоков
BlockNote (часть уже доступна через slash-меню; тулбар выносит частые наверх).
«Формула» вставляет кастомный LaTeX-блок (`notesMathBlock.jsx` — уже есть).
Счётчик слов/времени чтения — производное от тела.

### 6. Экспорт заметки (НОВОЕ, в шапке редактора)
Иконка share/⋯ в тулбаре редактора → экспорт заметки в **PDF/Word** (в проекте
уже есть `html2pdf.js` и экспорт КТП в Word — переиспользовать). Полезно, чтобы
отдать конспект ученику/родителю.

## Interactions & Behavior
- Клик по заметке в списке → выбор (`activeId`), рендер в редакторе + контексте.
- Быстрый захват: Enter → создать `idea`+`is_inbox`, не открывать, очистить поле.
- Чипы типов / сегменты / класс / поиск — комбинируемые фильтры списка.
- Пилюля типа в редакторе → меню смены типа (патч `note.type`).
- Сворачивание контекст-панели — стрелка в её шапке (состояние персистентно).
- Отметка ученика → раздел в теле + `links[student]` (как сейчас).
- Чекбокс в «Задачи из заметки» ↔ чек-айтем тела; «В Все задачи» — экспорт.
- Все патчи — оптимистичные (как сейчас `patchNote`/`patchActive`), автосейв тела
  с дебаунсом и индикатором «сохранено».
- Hover/Focus — как в системе: фон `--bg-hover`, фокус-ринг из `tokens.css`.

## State Management
Расширяет текущий стейт `NotesWorkspace.jsx`:
- `notes[]`, `activeId`, `view` (all/inbox/archive), `searchQ`, `groupFilter` —
  **как сейчас**.
- **Добавить:** `typeFilter` (all|lesson|plan|idea|call|obs); `railCollapsed`
  (bool, персистентный).
- Поля заметки: существующие `title, body(json), note_date, group, lesson,
  links[], is_pinned, is_inbox, is_archived` + **новое `type`**.
- Производные: `inboxCount` (есть), `noteTasks` (из тела — чек-айтемы),
  `backlinks` (обратный поиск по `links[type='note']`), `wordCount`.

## Data fetching
Источники прежние: `api.getNotes`, `getTeachingGroups`, `getLesson`/`getLessonNote`,
`updateNote`, `createNote`. **Новое:** запись задач в коллекцию «Все задачи» при
экспорте чек-листа; обратный запрос бэклинков (по `links`). Схема
`teacher_notes` (см. HowItWorksPage): `body(json), note_date, tags, links,
is_pinned` — добавить `type`.
