# Handoff: Редизайн раздела «Моё пространство» → экран «Сегодня»

## Overview
Это редизайн стартового экрана раздела **«Моё пространство»** (маршрут `/app/today`,
компонент `TodayDashboard.jsx`) в приложении Lemma / ege-tasks.

Цель — превратить «Сегодня» из набора статичных виджетов в рабочий дашборд
«одного окна»: учитель с него ведёт расписание уроков, готовит материалы,
отслеживает сдачу/успеваемость, ведёт заметки и каникулярные задания — не уходя
на отдельные страницы. Экран стал плотнее, функциональнее и получил живой
блок «Идёт сейчас».

## About the Design Files
Файл `Сегодня - Моё пространство.dc.html` — это **design reference**, прототип на
HTML, показывающий итоговый вид и поведение экрана. Это **НЕ** production-код для
копирования напрямую.

Задача — **воспроизвести этот дизайн внутри существующего кодового кода**
(`generation-test/ege-tasks`, React + Ant Design + Vite), используя уже принятые
там паттерны: компоненты из `src/components/workspace/ui/`, токены из
`src/theme/tokens.css`, AntD `ConfigProvider`. Прототип написан на инлайн-стилях
для скорости — в коде их быть не должно: всё переводится на CSS-переменные/токены
и существующие UI-компоненты.

> Формат `.dc.html` — самодостаточный: открой файл в браузере, чтобы увидеть
> дизайн «живьём». `support.js` — рантайм прототипа, в кодовую базу он не нужен.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, состояния. Воспроизводить
пиксель-в-пиксель средствами текущего дизайн-системного слоя Lemma. Все значения
ниже совпадают с `tokens.css` — переиспользуй их, а не хардкодь хексы.

## Архитектура экрана

Страница рендерится **внутри уже существующего AppShell** (сайдбар + топбар из
`App.jsx`). В прототипе сайдбар и топбар нарисованы для контекста — **их
реализовывать заново не нужно**, они уже есть. Реализуется только содержимое
`<main>` для маршрута `/app/today`.

Контентная область: `max-width: 1180px`, центрирована, паддинг `24px 26px 56px`.

Вертикальный порядок блоков:
1. **Шапка страницы** + **навигатор недели** (одна строка, space-between, wrap)
2. **Hero-ряд**: «Идёт сейчас» (≈1.55fr) + кластер KPI 2×2 (≈1fr) — `gap:16px`
3. **Двухколоночная сетка** `1.55fr / 1fr`, `gap:16px`, `align-items:start`:
   - **Левая колонка**: «Расписание на сегодня», «К подготовке на неделе»
   - **Правый рейл**: «Требует внимания», «Заметки», «Каникулярные задания»

Сетки — CSS grid. На узких экранах (<1100px) сетки схлопываются в одну колонку
(правый рейл уходит вниз).

## Screens / Views — блоки экрана

### 1. Шапка страницы
- **Eyebrow** (дата): `Вторник, 10 июня` — `10.5px / 600 / uppercase / tracking .08em`, цвет `--ink-4`.
- **H1**: `Доброе утро, Анна` — `26px / 600 / tracking -.03em` (= `--page-title-*`), цвет `--ink`.
- **Подпись**: `5 уроков · 4 дедлайна на этой неделе · 3 заметки в инбоксе` — `13.5px`, `--ink-3`.
- Приветствие зависит от времени суток (утро/день/вечер); имя — из профиля учителя.

### 2. Навигатор недели (справа в шапке)
- Контейнер: `background #fff`, `border 1px solid --rule`, `radius 10px`, паддинг `5px`, `display:flex`.
- Стрелки ‹ › по краям (переключение недели), между ними 7 кнопок-дней.
- День: `min-width 42px`, `height 46px`, `radius 7px`, колонка из: подпись дня
  (`10px/600/uppercase`), число (`15px/600`), точка-индикатор (есть уроки → `--accent`).
- **Сегодня**: фон `--accent` (#2B4BFF), текст белый, точка белая полупрозрачная.
- Дни без уроков: число цветом `#C2C6CE`, точки нет.
- Выходные можно скрывать (см. tweak `showWeekend`).

### 3. «Идёт сейчас» (hero, левая часть)
Главная новая фича — живая карточка текущего урока.
- Контейнер: тёмный градиент `linear-gradient(135deg,#0D1321 0%,#1B2444 60%,#23306b 100%)`,
  `radius 14px`, паддинг `20px 22px`, текст белый, `box-shadow 0 6px 24px rgba(13,19,33,.18)`.
  Поверх — радиальный блик `radial-gradient(420px 200px at 88% -10%, rgba(43,75,255,.45), transparent)`.
- Верхняя строка: пульсирующая точка (#34D399, анимация opacity 2s) + eyebrow
  `Идёт сейчас · до 11:00` (цвет `#9FB4FF`) + справа моно-время `10:15–11:00` (`#C7D2FE`).
- Чип группы (полупрозрачный белый фон, цветная точка группы) + название предмета.
- Тема урока — `19px / 600`.
- **Прогресс-бар** урока (доля прошедшего времени): трек `rgba(255,255,255,.16)`,
  заливка `linear-gradient(90deg,#60A5FA,#34D399)`.
- Кнопки действий: **Посещаемость** (белая, primary), **Материалы · N**, **Заметка**
  (полупрозрачные), справа текст-кнопка **Завершить →** (`#9FB4FF`).
- Если урока сейчас нет — карточка показывает **следующий** урок («Далее в HH:MM»),
  без прогресс-бара и пульса.

### 4. KPI-кластер 2×2 (hero, правая часть)
Четыре компактные карточки (`grid 1fr 1fr`, `gap 12px`). Заменяют старые крупные стат-блоки.
- Карточка: `#fff`, `border --rule`, `radius 12px`, паддинг `14px 15px`, `shadow-sm`,
  flex-колонка space-between, кликабельна.
- Сверху: иконка в цветном квадрате `30×30 radius 8px` (цвет/фон по тону) + опц. тег-бейдж справа.
- Снизу: значение `30px/600/tracking -.035em` (= `--stat-value-*`) + подпись `11.5px`, `--ink-3`.
- Карточки:
  - **Уроков сегодня** = `5` — тон blue, иконка часов.
  - **К подготовке** = `2`, тег «неделя» — тон amber, значение цветом amber, иконка гаечного ключа.
  - **Дедлайнов** = `4`, тег «2 нед.» — тон violet, иконка календаря.
  - **Просрочено** = `2` — тон rose, значение цветом rose, иконка «!».

### 5. «Расписание на сегодня» (левая колонка)
Карточка-секция. Шапка: иконка часов (`--accent`) + заголовок + счётчик
`5 урока · 1 проведён` + текст-кнопка **+ Урок** справа.
Тело — таймлайн-список уроков. Каждая строка (`radius 9px`, паддинг `11px 10px`):
- Слева: время начала (`14px/600`, tabular-nums) и конца (`11px`, `--ink-4`), выровнены вправо, ширина 50px.
- Дальше: точка-маркер статуса (`11×11 radius 50%` + кольцо `box-shadow 0 0 0 3px <ring>`) и вертикальная линия-коннектор `width:2px` цвета `--rule-soft`.
- Контент: название предмета (`14px/600`) + чип группы; тема урока + ссылка на КТП (`12.5px`, `--ink-3`, обрезается ellipsis); ряд мета-чипов:
  - чип статуса (проведён/идёт сейчас/запланирован);
  - чип посещаемости `25 / 26` (если есть);
  - чип «материалы N» (если N>0);
  - чип-предупреждение «материалы не готовы» (тон amber) если N=0.
- Справа: кнопка **Подготовить** (фон `--c-amber-soft`, текст `#B45309`) — только если материалов нет; иконка-кнопка «заметка/редактировать» `30×30`.
- Текущий урок: фон строки `#F5F8FF`, рамка `1px solid #D5E0FF`.
- **Статусы** (метка / fg / soft / точка):
  - `проведён` — teal (`--c-teal` / `--c-teal-soft`)
  - `идёт сейчас` — blue (`--c-blue` / `--c-blue-soft`)
  - `запланирован` — neutral (`--ink-3` / `--bg-sunken`, точка `#9AA0AC`)

### 6. «К подготовке на неделе» (левая колонка)
Новый блок — бэклог уроков, к которым ещё не прикреплены материалы.
Шапка: иконка-«солнце»/настройки (тон amber) + заголовок + подпись + текст-кнопка **КТП →**.
Строки: дата-плашка (`38×38 radius 9px`, день+число, цвет по тону группы) + тема урока + чип группы + мета (`12px`, `--ink-4`, напр. «КТП §19 · 2 урока без материалов») + кнопка **Собрать урок** (фон `--bg-sunken`).

### 7. «Требует внимания» (правый рейл)
Шапка: иконка «!» (тон rose) + заголовок + текст-кнопка **Журнал →**.
Строки: цветной вертикальный бар слева (`width 4px`, цвет по срочности) + заголовок задачи + чип группы + подпись (`12px`, `--ink-4`) + бейдж срока справа (`−2 дня` / `сегодня` / `+3 дня`, цвет по срочности: rose/amber/neutral).

### 8. «Заметки» (правый рейл)
Шапка: иконка документа (тон violet) + заголовок + текст-кнопка **Все →**.
Строки: иконка типа (📌 закреплённая — amber / inbox — neutral) + текст заметки (обрезается ellipsis) + опц. чип группы. Снизу — пунктирная кнопка **+ Бросить мысль в инбокс** (`border 1px dashed --rule`, фон `--bg-hover`).

### 9. «Каникулярные задания» (правый рейл)
Шапка: иконка «солнце» (тон teal) + заголовок + текст-кнопка **Все →**.
Карточки с прогрессом: название + чип группы + процент справа (цвет по тону) → прогресс-бар (`height 7px`, трек `--bg-sunken`, заливка цветом тона) → мета-строка (`12px`, `--ink-4`).

## Interactions & Behavior
- Все строки/карточки кликабельны → переход в соответствующий раздел/сущность
  (урок → редактор урока, задача → журнал, заметка → заметки, и т.д.).
- **Навигатор недели**: клик по дню → перезагрузка расписания на выбранную дату;
  стрелки ‹ › → ±неделя. Активный день подсвечен `--accent`.
- **Hero «Идёт сейчас»**: прогресс-бар считается от текущего времени между началом
  и концом урока (обновлять раз в минуту). Пульс-точка — CSS-анимация opacity 2s.
  «Завершить» → закрывает урок / открывает быструю отметку посещаемости.
- **Кнопка «Подготовить» / «Собрать урок»** → запуск флоу сборки материалов урока
  (генераторы/рабочие листы — существующий функционал приложения).
- **Топбар «Создать»** и **+ Урок** → создание урока/добавление в расписание.
- **Hover**: карточки/строки — лёгкая подсветка фона (`--bg-hover`); кнопки —
  затемнение/осветление на ~6–8%.
- **Focus**: используется единый фокус-ринг из `tokens.css`
  (`box-shadow: 0 0 0 3px --accent-soft, 0 0 0 4px --accent`).
- Анимации сдержанные: только пульс точки и плавные transition фона/прогресса.

## State Management
Состояние «Сегодня» собирается из нескольких источников приложения:
- `selectedDate` / `weekStart` — выбранная дата и неделя навигатора.
- `lessons[]` за дату — из расписания/КТП: `{ id, time, end, subject, topic, ktpRef, group, tone, status: 'done'|'now'|'planned', materialsCount, attendance }`.
  Статус `now` вычисляется по текущему времени; `currentLesson`/`nextLesson` —
  производные для hero-карточки.
- `kpis` — агрегаты: уроков сегодня, к подготовке (уроки недели без материалов),
  дедлайнов (2 нед.), просрочено.
- `prepBacklog[]` — уроки недели без прикреплённых материалов.
- `attention[]` — объединение дедлайнов и непроверенных/несданных работ из журнала.
- `notes[]` — закреплённые заметки + инбокс.
- `summerTasks[]` — каникулярные программы с прогрессом сдачи.
- Tweaks (локальные предпочтения, хранить в профиле/localStorage):
  `hideDone` (скрывать проведённые уроки), `showWeekend`, `focusMode` (прятать правый рейл).
